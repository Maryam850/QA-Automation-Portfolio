# QA Automation & Security Testing Portfolio

This repository showcases professional-grade automated test cases and security validation scripts built to ensure application quality and resilience.

## Features
- **Robust Automation:** Built with Python and Selenium WebDriver using explicit waits.
- **Maintainable Architecture:** Designed with future Page Object Model (POM) scalability in mind.
- **Security Mindset:** Includes input validation testing to prevent common vulnerabilities.

## Tools & Technologies
- **Language:** Python 3.x
- **Framework:** Selenium WebDriver
- **Methodology:** Agile / Data-Driven Testing Simulation

## How to Run
1. Install dependencies: `pip install selenium`
2. Run the script: `python test_ecommerce.py`
